# Stars! Libraries

The desktop client maintains separate libraries for games and race designs.

## Language

**Game library**:
The collection of games managed by Stars! for the current user.

**Managed game**:
A game kept in its own library folder under a unique name valid as a filename across supported platforms, containing its existing family of game files. An imported game is a copy independent of its source files.

**Race design**:
A reusable race definition used when creating a game, distinct from a player's turn in an existing game.

**Race library**:
The collection of race designs managed by Stars! for the current user, separate from the game library.

**Player turn**:
A player's view of a game for a particular year. A managed game can contain turns for several players, and the user chooses which player to open.

**Game export**:
A complete copy of a managed game for use outside its library.

**Orders export**:
A copy of one player's saved orders for delivery to the game's host.

**Library name**:
The unique name identifying a managed game within its user's library, valid as a filename and compared without regard to capitalization. Separate copies of the same game have different library names.

**Game title**:
The title stored within a game, retained when its library name changes.

**Exchange basename**:
The remembered original game filename stem used when exporting orders to an external host, independent of later library renames.
