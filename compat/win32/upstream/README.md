# Pinned Free API source reference

`free-api/` is an unmodified selection from upstream commit
`8337b2499ca28423623f624d4351992ca3f2a22f`: public headers, runtime sources,
README, license and scope documents. It is not compiled, and is not a
standalone upstream build (external libraries, build helpers and tests are
omitted). Its includes must not replace Stars' ABI-checked headers.

See `free-api/ORIGIN.json` for source hashes and `docs/FREE-API-ADOPTION.md`
at the repository root for coverage, adaptations and next steps. Working
local C11 implementations live in `compat/win32/src/`.
